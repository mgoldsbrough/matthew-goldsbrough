# Matthew Goldsbrough GitHub Pages Site

This repository contains a static one-page profile site ready for GitHub Pages.

## Files

- `index.html`: the page content and metadata.
- `styles.css`: the page styling.
- Profile image is loaded from Matthew's public Gravatar image URL.
- `.nojekyll`: tells GitHub Pages to serve the static files directly.

## GitHub Pages

The intended public URL is:

`https://mgoldsbrough.github.io/matthew-goldsbrough/`

To enable it, go to `Settings` then `Pages`, choose `Deploy from a branch`, select the `main` branch and `/root`, then save.

For a custom domain, add the domain in the same Pages settings screen, then update the DNS records at the domain provider.
